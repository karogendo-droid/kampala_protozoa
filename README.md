# Kampala wastewater enteric protozoa

## Study
Enteric Protozoan Detection in Wastewater from Two Treatment Plants
in Kampala, Uganda: A Secondary Analysis of Published Shotgun Metagenomes.

## Candidate dataset
NCBI BioProject: PRJNA1091428

## Current status
Computing setup only. Dataset eligibility, metadata, sample independence,
and read availability still require verification.

No protozoan detection results have been generated.

## Scope
Enteric protozoan sequence detection, descriptive specimen-level
distribution, and exploratory comparison with selected bacterial signals.
Antimicrobial resistance is outside the study scope.

## Repository contents
Software environment specifications, analysis scripts, public metadata,
and documentation.

Original sequencing reads, reference databases, credentials, and
human-derived sequence outputs must not be committed.
