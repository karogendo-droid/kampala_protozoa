# Publication-supporting results

This directory contains selected summary tables corresponding to the finalized Kampala enteric protozoa investigation.

## Preliminary taxonomic assignments

`genus_counts_all_six.csv`

Genus-level candidate read-pair counts from all six investigated sequencing runs.

These counts are preliminary taxonomic assignments, not confirmed organism detections.

## Competitive genomic alignment

`corrected_genus_support.csv`

Read-pair counts satisfying the final predefined genus-concordant genomic-alignment criteria.

`genomic_distribution_summary.csv`

Distribution of qualifying alignment pairs across reference contigs and genomic intervals.

These measurements do not establish whole-genome coverage or organism identity.

## Complementary marker assessments

`whole_metagenome_marker/`

Marker assessment of the complete human-screened sequencing datasets, including specimen-level summaries.

Three isolated target-associated read pairs were accepted, but no specimen–genus combination met the multi-fragment corroboration threshold.

`final_corrected_marker_evidence.csv`

`new_PR2_marker_evidence.csv`

Results from the separate targeted marker assessment of Kraken2-selected candidate reads.

This assessment used different read selection and acceptance rules from the whole-metagenome marker investigation.

## Interpretation

The combined analyses did not establish corroborated organism-level detections under the applied criteria.

These findings do not establish that enteric protozoa were absent from the wastewater or that existing surveillance programmes missed infections.

The summary tables should not be interpreted as measurements of parasite concentrations, infection prevalence or diarrhoeal disease burden.
